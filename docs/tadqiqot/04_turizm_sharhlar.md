# 04. Turizm / dam olish maskanlari: reklama vs haqiqat, soxta sharhlar (Smart Tourism Review)
Tayyorlangan: 2026-11-17. Manba: veb-qidiruv (stat.uz va gov.uz sahifalariga to'g'ridan-to'g'ri kirish 403 berdi, shuning uchun ular qidiruv natijasi/ikkilamchi manbalar orqali keltirilgan). Har raqam yonida URL. [UNVERIFIED] = tasdiqlanmagan.

## 0. Qisqa xulosa (TL;DR)
- Bozor katta: 2025 da ichki turistik safarlar 137.7 mln (stat.uz), lekin 53.7% (73.9 mln) "do'st/qarindoshlarni ko'rish" -- dam olish maskanlari ulushi ancha kichik.
- Og'riq REAL, lekin eng qattiq hujjatlangan shakl = SOXTA SHARH EMAS, balki (a) dacha ijarasida oldindan to'lov firibgarligi, (b) OTA/booking platformalaridagi noto'g'ri ma'lumot (yulduz, ro'yxatdan o'tmagan obyekt), (c) norasmiy/soyadagi ijara bozori.
- O'zbekistonda soxta sharhlar (Google/Yandex/2GIS) haqida mahalliy, hujjatlashtirilgan dalil TOPILMADI (faqat 1 ta anekdot, Tripadvisor). Global dalil esa kuchli.
- Davlat o'zi shu bo'shliqni to'ldirmoqda: 2026-aprel loyiha (dacha reyestri + narx monitoringi + Soliq ilovasi), Turizm qo'mitasi "yagona milliy turizm platformasi", Sertifikatlash markazi booking-saytlarni monitoring qiladi. Bu: (1) raqobat/hamkorlik xavfi, (2) xaridor ("buyer") imkoniyati.
- Eng kuchli burchak 2 kunga: "Dacha/maskan ishonch skori" -- reklama-vs-haqiqat (ommaviy sharhlar + rasmlar + reyestr/registratsiya holati) + egalikni tekshirish (firibgarlikdan himoya), soxta sharh detektori faqat bitta modul sifatida.

## 8. Realistic 2-day MVP ideas
1. "Dacha Ishonch Tekshiruvchi" Telegram bot (eng aniq og'riq): foydalanuvchi e'lon rasmlari/telefon/Telegram username/narx yuboradi -> (a) teskari rasm qidiruv/dublikat bazasi, (b) telefon/kartaga oid ommaviy shikoyatlar bazasi (jamoa to'playdi), (c) narx anomaliyasi (OLX scrape bilan mintaqa mediani), (d) "zaklad uchun xavf: yuqori/o'rta" + tekshiruv ro'yxati (video qo'ng'iroq, egalik). Maqsad: firibgarlik oldini olish. Dalil bor (podrobno, kun.uz).
2. "Real Picture" skor Charvak/Chimgan/Zomin/Bo'stonliq obyektlari uchun: Google Maps/Yandex sharhlarini (Places API yoki scrape; ToS/limitlarga e'tibor) 30-50 obyekt uchun yig'ib, LLM bilan aspektlarga ajratish (toza, xizmat, narx/haqiqat, kutish) va "reklama va'dasi vs sharh haqiqati" jadvali; sharhlarni uzbek/rus/ingliz tillarida qayta ishlash. Soxta-signal: bir kunda ko'p 5 yulduz, 1-sharhli akkauntlar, shablon matn, yulduz-matn nomuvofiqligi. Haqiqiy aniqlik ISBOTLANGAN BO'LMAGAN -- faqat "shubhali belgi" deb ko'rsating, "soxta" deb emas.
3. Reklama-vs-haqiqat foto modul: e'lon rasmlari (Instagram/OLX) va Google Maps mehmon rasmlari -> VLM bilan "ko'rsatilgan: basseyn, sauna, tog' manzara" vs "mehmon rasmida tasdiqlanadi" -- demo-yaxshi, 2 kunda mumkin (10-20 obyekt qo'lda). AI-yaratilgan rasm detektori ishonchsiz -- baho sifatida "ehtimol" deb bering.
4. Tasdiqlangan sharh boti: fiskal chek QR (ofd.soliq.uz havolasi yoki rasm) -> parsing -> sana/summa/STIR (egasi) -> sharh "Tasdiqlangan tashrif" belgisi. Demo uchun mock chek bilan; real API tasdiqlanmagan. Cheklov: dacha norasmiy -- chek yo'q; shuning uchun hybrid: chek YOKI to'lov skrinshoti YOKI geolokatsiya.
5. Davlat tomoni: Reyestr cross-check paneli (Booking/OLX e'lonlari vs oilaviy uylar reyestri) -- Sertifikatlash markazi qo'lda qilayotgan ishni avtomatlashtirish (458 buzilish topgan jarayon). B2G pitch: "tizimli monitoring".
Tavsiya: pitch = (1) + (2) + (4) ni bitta oqimda: "Zaklad to'lashdan oldin tekshir -> tashrifdan keyin chek bilan tasdiqla -> reklama vs haqiqat skori". Soxta sharh AI'ni "signal" sifatida, asosiy narrativ emas.
