## 8. MVP (2 kun, sintetik ma'lumot bilan)
1. Sintetik ma'lumot: 40-60 filial/BXM/BXO x 36 oy x 6-7 opex kategoriya (openinfo Apex tuzilmasiga mos: maosh, ijara, sayohat, ma'muriy, vakillik, amortizatsiya, kommunal, aloqa); drayverlar: xodim, m2, mintaqa, ish soatlari, kVt*soat x tarif (2026-iyun tarif sakrashi kiritilgan), inflyatsiya (CBU), USD/UZS. Anomaliyalar (inject): ikki marta to'langan hisob, noto'g'ri kategoriya, kommunal spike, limit buzilishi. Ochiq makro qatorlar real (CBU).
2. Dvigatel: (a) drayver-asosli + ETS/LightGBM prognoz, backtest MAPE ko'rsatish (sintetikda - ochiq ayting); (b) stsenariy slayderlari: inflyatsiya, USD/UZS, asosiy stavka, tarif -> daromad/xarajat/foyda; (c) filial taqsimlash: DEA skor + LP bilan byudjet tavsiyasi; (d) plan-fakt: yillik/oylik tezkor "limit 80/100% ga yetadi" bashorati; (e) anomaliya: robust z-score + isolation forest + qoidalar (duplikat, kategoriya noto'g'ri - LLM/klassifikator); (f) LLM variance izohlovchi o'zbek tilida: kirish - deterministik hisoblangan driver ajratmalari, chiqish - 2-3 jumla + tavsiya (hallutsinatsiyani oldini olish uchun faqat berilgan sonlar).
3. UI: Streamlit/Next.js: bitta bosh sahifa, harita/filial reytingi, slayderlar, "nega" tugmasi, "import Excel" (haqiqiy bank fayli sig'ishi ko'rsatkichi).
4. Demo skript: 3 daqiqa - stsenariy (stavka -1pp, USD +5%) -> 10 soniyada yangi byudjet; filial X ogohlantirish; anomaliya aniqlandi; o'zbekcha izoh. Slaydda: "real banklar uchun on-prem, data tashqariga chiqmaydi".
5. Tavakkal: sintetik aniqlikka da'vo qilmang; "Excel/1C bilan integratsiya" orqali pilot yo'lini ko'rsating.
